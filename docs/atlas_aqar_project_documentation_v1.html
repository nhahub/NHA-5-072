System Concept & Core Value Proposition

Atlas AQAR (أطلس عقار) is a production-grade, bounded multi-agent AI system designed to conduct autonomous real-estate research, due-diligence, and investment analysis tailored specifically to the Egyptian property market. Moving beyond standard single-turn LLM chatbots, Atlas AQAR implements a stateful, cyclic LangGraph graph workflow that breaks complex investment prompts into structured sub-tasks, gathers grounded evidence via vector retrieval and external verification, performs exact financial calculations, and passes all outputs through an automated editorial Critic agent.

A foundational design principle of Atlas AQAR is deterministic financial computation: all mortgage amortization, rental yields, capital growth projections, and sensitivity models are executed exclusively in dedicated mathematical algorithms, entirely preventing LLM arithmetic hallucinations. Every claim made in generated investment reports is directly tagged with an audit-ready Evidence ID (e.g., [E001]).

Project Overview

Market challenges, objectives, system boundaries, technology selections, and architectural foundations.

2.1 Background & Problem Statement

The Egyptian real-estate ecosystem is among the most dynamic investment landscapes in North Africa and the Middle East. However, individual and institutional investors face severe informational friction:

  • Data Fragmentation: Unit listings, pricing indices, and developer track records are scattered across disparate websites, social groups, and informal brokers.
  • Information Asymmetry: Potential buyers lack verified data on developer delivery track records, historical delays, and construction solvency.
  • Financial Calculation Opacity: Real-estate installment plans often include hidden maintenance deposits, backloaded balloon payments, and fluctuating interest formulas that retail investors struggle to assess.
  • GenAI Unreliability: Standard LLMs hallucinate property prices, invent developers, and introduce gross calculation errors when asked for real-estate ROI forecasts.

The Solution: Atlas AQAR provides an automated, evidence-grounded research co-pilot that combines semantic vector search, deterministic financial amortization, multi-agent cognitive critique, and professional report generation into a unified platform.

2.2 Vision, Mission & SMART Objectives

Vision: To become the leading trusted, verifiable AI intelligence engine for property research and real-estate investment decision-making in Egypt.

Mission: To democratize institutional-grade property due diligence by combining agentic reasoning with rigorous mathematical determinism and empirical evidence verification.

Objective 1 (O1)
Autonomous Task Decomposition
Deconstruct user investment queries into 3–6 dependency-ordered sub-tasks executed systematically.
Objective 2 (O2)
Deterministic Financial Engine
Deliver 100% accurate mortgage amortization, ROI, and sensitivity analysis via non-LLM Python algorithms.
Objective 3 (O3)

Objective 6 (O6)

Deploy via FastAPI backend, Streamlit interactive dashboard, and Docker Compose orchestration in 4 weeks.

4.4 Assumptions & Operational Constraints

Core Project Assumptions
  • All developers operate on Python 3.11+ with local Docker Desktop installed.
  • Curated JSON datasets accurately reflect representative Egyptian real-estate market segments in New Cairo, New Capital, and Sheikh Zayed.
  • At least one live API provider key (OpenAI / Gemini / Anthropic) is accessible for validation, while offline mock mode is available for local testing.
  • Four-week timeline is firm with fixed weekly sprint reviews.
Operational Constraints
  • Maximum of 10 LangGraph workflow iterations per research request to prevent infinite loops.
  • Maximum of 3 Critic revision retries before forced report synthesis.
  • Zero arithmetic calculations delegated to LLM text generation.
  • System must be fully runnable locally without mandatory paid cloud dependencies.

Appendix, Glossary & Revision Log

Terminology definitions, abbreviation index, revision tracking log, and official references.

Glossary of Key Technical Terms

Term Technical Definition within Atlas AQAR
Agentic Workflow An AI design pattern where an LLM coordinates reasoning, tool invocation, observation, and state updates iteratively rather than in a single-prompt response.
LangGraph A specialized framework built on LangChain for building stateful, multi-actor applications with cyclic graph computation and persistence.
GraphState The centralized, immutable Pydantic v2 data model passed between all agents in the workflow, tracking queries, sub-tasks, evidence records, drafts, and critique notes.
Evidence Arsenal A structured repository of verified facts, listing specifications, and financial calculations collected during the research phase, each carrying a unique Evidence ID.
Evidence ID A deterministic citation tag (e.g., [E001], [E002]) assigned to raw data items and referenced inline throughout generated analytical reports.
Deterministic Financial Engine A pure Python mathematical module executing mortgage amortization, ROI, and sensitivity analysis arithmetically, completely bypassing LLM probabilistic text generation.
ReAct Loop A cognitive pattern (Reasoning + Acting) where the Researcher agent generates thoughts, executes tool actions, observes results, and loops until sufficient evidence is accumulated.
Critic Agent An editorial inspection agent that evaluates draft reports against a 7-point rubric (factual grounding, math accuracy, completeness) and issues conditional approval or revision feedback.
ChromaDB An open-source, embedded vector database used in Atlas AQAR to store and semantically retrieve high-dimensional embeddings of properties and market reports.
